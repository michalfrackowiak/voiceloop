Behaviour delivered:
- Detectors compare baseline/current replay windows and report counts plus signed descriptive deltas (mean, median, decile buckets, total variation, per-status rates). They never claim causality, evaluate promotion, or change P2-09 thresholds.
- Windows with fewer than `min_window_samples` report deltas but `drifted=false` and `enough_data=false`.
- Policy triggers only when `new_verified_count >= min_new_verified` **and** (`drifted` or a valid `ManualOverride`). A `scheduled_tick` is audit-only and can never be a reason. Manual overrides require a pseudonymous actor token and an allowlisted coded reason; the actor/reason are written to an injected audit sink before any pipeline invocation, including when the volume leg fails.
- Fixture replay splits by call ID, uses an injected score adapter, and hash-checks the read-only fixture and sealed golden stand-in before replay.
- All decision/report/audit payloads carry `SYNTHETIC/FIXTURE STAND-IN - NOT PRODUCTION DRIFT EVIDENCE` and pass `assert_no_sensitive_text()` before serialisation.
