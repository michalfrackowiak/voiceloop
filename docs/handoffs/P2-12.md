Known gaps / follow-ups:
- Dataset manifest schema 1.0.0 carries `source_call_ids` but not per-example IDs. Example → call therefore needs an injected exact example index; without one the query fails closed. This is a contract limitation, not a fabricated link.
- `TrainerResult.lineage` is optional in the P2-06 schema; this package rejects results without complete lineage rather than guessing. Registry model IDs default to the exact `run_id` unless a `model_id_for_run` mapping is injected.
- Storage/auth are fake-only by design: no transaction spans tombstone + flags + audit. A flag-sink failure leaves the call tombstoned (fail closed), emits `deletion_failed` and raises; a production adapter should add write-ahead/retry semantics.
- No physical deletion, retraining, alias/promotion change or sealed-golden change is performed. Erasure remedy and lawful basis remain human/counsel questions; `docs/compliance.md` stays OPEN — counsel review required and no conclusion here is final.
- `VOICELOOP_LINEAGE_AUDIT_LOG_PATH` is a seam for a future file-backed audit adapter; the shipped sink is in-memory. Tenant scoping (P4-05) is not modelled.
- Escalation guarantee is scoped to this package: there is no public mutable matrix, no role-assignment API and no attacker-controllable role string. A production identity-provider adapter must still verify credentials and construct `Principal`; none ships here.
