```python
from services.ingest.failopen import (
    BoundedBuffer,
    BufferedEvent,
    EnqueueResult,
    FailOpenMetrics,
    FailOpenSettings,
    FlushResult,
    HealthSnapshot,
    HealthStatus,
    RecordingSink,
    ShedReason,
    StorageSink,
)

buffer = BoundedBuffer(sink, FailOpenSettings())
receipt = buffer.enqueue(event)
result = buffer.flush()

counters = buffer.counters()
buffer.close()
```

- `BoundedBuffer(sink, settings=None, *, metrics=None)` — `sink` implements `StorageSink`.
- `BoundedBuffer.enqueue(event, timeout_ms=None)` — returns `EnqueueResult(accepted, signal, event_id, reason)`; never raises.
- `BoundedBuffer.flush(max_events=None, timeout_s=None)` — returns `FlushResult(flushed, remaining, timed_out, storage_failures)`; never raises.
- `BoundedBuffer.health()` — `HealthSnapshot`; `to_dict()` is JSON-ready. `counters()` returns the five cumulative counters. Context-manager use is supported.
- `FailOpenSettings` fields: `backend`, `capacity`, `enqueue_timeout_ms`, `max_payload_bytes`, `writer_workers`, `flush_timeout_s`, `degraded_ratio`, `disk_dir`.
- `RecordingSink.set_down(bool, error=...)` and `.written` are test-only fakes; `ShedReason` is `"none"|"queue_full"|"invalid_event"|"internal_error"`; `HealthStatus` is `"healthy"|"degraded"`.
