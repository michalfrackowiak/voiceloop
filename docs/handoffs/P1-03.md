Task: P1-03 Python SDK
Agent role: sdk (worker agent)

What changed (files/paths):
- `sdk/__init__.py` — public exports for `log_turn`, `SdkClient`, `SdkSettings`,
  `EnqueueStatus`, transports, metrics, circuit breaker and audio helpers.
- `sdk/client.py` — caller-side `enqueue`/`log_turn` (shallow copy, bounded
  append, no validation/I/O/logging in the call path) plus one daemon worker
  that deep-copies, validates against `turn_event.schema.json`, sends with a
  timeout, retries, and counts every drop/shed/failure. Includes
  `wait_until_idle()`, `pending_event_ids()`, `close()`, context-manager
  support, a circuit breaker and a process-wide default client.
- `sdk/transport.py` — `TurnTransport` protocol, deterministic
  `InMemoryTransport` (delay/failure/sleeper injection), optional lazy
  `HttpTransport` using httpx, and `TransportError` (a `TransientError`).
- `sdk/circuit_breaker.py` — three-state breaker with injectable monotonic
  clock, failure threshold and one-probe half-open recovery.
- `sdk/metrics.py` — lock-protected counters and immutable
  `SdkMetricsSnapshot`.
- `sdk/settings.py` — typed `SdkSettings` with the `VOICELOOP_SDK_` env prefix
  via `voiceloop_common.settings`.
- `sdk/audio.py` — `AudioCapture`, `capture_wav`, `capture_audio` alias and
  `capture_pcm`; WAV rates read with stdlib `wave`, raw frames preserved, no
  resampling (8 kHz supported unchanged).
- `sdk/README.md` — run/test/contract notes, settings table, fail-open policy,
  metrics and transport documentation.
- `tests/unit/sdk/` — 18 deterministic unit tests: caller latency with a
  sleeping fake transport, no exceptions on bad input, background validation
  failures recorded as metrics, breaker opening/shedding, retry flush after
  recovery, bounded queue oldest-drop with counter, 8 kHz/16 kHz audio
  preservation, breaker recovery probe, settings prefix and transport fakes.
