## What is exercised

1. Synthetic labels → dataset: reviewed non-golden `fixture-standin-*` calls,
   sealed golden call IDs excluded, exports built via public dataset APIs.
2. P3-01 training: public `TrainerRunner` with `whisper-lora` and
   `HfJsonExampleLoader`; fake merged-adapter URI is converted to a distinct
   `converted://` artifact URI and logged once in memory.
3. P3-04 safety probe: the exact converted artifact is stored in a
   `ReadOnlyArtifactStore`, probed (`pass`), evaluated and validated with
   `validate_stt_report`. A checkpoint URI substitution cannot change the
   evaluated artifact. This pass is deliberately **read-only safety evidence**,
   not the passing promotion report.
4. P1-07 promotion evidence: paired `identity`/`oracle` reports for the derived
   fixture, labelled with the STT stand-in label and gated by the unchanged
   P2-09 rule. The `other_languages` slice is marked with a temporary
   `(SYNTHETIC-Ø)` suffix in a derived fixture; the committed fixture is not
   touched.
5. P3-07 shadow evidence: bounded mirror, scripted candidate/champion runners,
   synthetic outcomes, `score_comparison`, `build_shadow_report` and
   `validate_shadow_report`. The report says
   `promotion_decision: not_evaluated` and contains no alias, gate or threshold
   claim. The source is keyed by `(challenger_version, champion_version)` read
   from the gate alias store and binds both exact artifact URIs.
6. P3-08 STT promotion: `Gate.run(..., change_kind="stt")` consumes fresh,
   complete, synthetic-labelled shadow evidence. Promotes only when the e2e
   decision passes and the shadow evidence verifies; writes one hash-chained
   audit record.
7. P3-06 serving sync: `AliasSyncAgent` mirrors the promoted alias to both STT
   and parser serving targets; structured tick events carry the label.
8. P3-08/P2-09 rollback: one audited alias flip back to the champion, mirrored
   by the sync agent to both serving targets.
9. Real clock: `SystemClock` mirrors one labelled turn and proves the bounded
   latency assertion. No `FakeClock` evidence is presented as wall-clock proof.

Parser promotion remains on the default `change_kind="parser"` path with no
shadow source; a dedicated test proves P2-09 behaviour is unchanged.

## Failure injections

`test_stt_failure_injection.py` asserts fail-closed behaviour before any
promotion for:

- stale, non-synthetic, promotion-claiming, mismatched, incomplete, invalid and
  missing shadow evidence;
- multiple chained refusals in one labelled `PromotionRefusalLog`;
- valid shadow evidence paired with a regressing e2e report;
- empty/truncated output, silence hallucination and multilingual forgetting;
- checkpoint URI substitution;
- parser path without a shadow source.

Every refusal has a stable code, appears in a verified hash chain with the STT
label, and leaves aliases and the promotion audit untouched. No audio bytes,
names, emails, phone fragments, card digits or raw transcript text are written
to reports or logs.
