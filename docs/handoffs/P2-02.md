Known gaps / follow-ups:
- **Explicit conflict/tension with `context.md` §2 invariant 6:** the default random-slice fraction is constrained to 3–5%, but with exactly 36 synthetic fixtures no integer count falls inside that band (1 = 2.8%, 2 = 5.6%). Fixture tests therefore use the documented `random_slice_target` override (2 items for the main fixture settings; production leaves it unset). Selection is still seeded, score-blind, explicitly tagged `slice: random` and outside the failure filter; the exact percentage cannot be represented at this pool size. Flagged rather than silently changed.
- Random-slice items deliberately bypass both the failure filter and near-duplicate clustering: deduplicating them could bias the measured error rate. Each receives a singleton pseudo-cluster (`random-<event_id>`), so the output still has exactly one representative per cluster.
- `daily_cap` is per `build_queue` call; persistent per-day idempotency and reviewer-capacity feedback belong to orchestration/review lanes (P2-10/P2-03). Default 30 items/day comes from the roadmap's 5 h/week starting point, not measured throughput.
- Cluster similarity is a deterministic stdlib heuristic (not phonetic models or embeddings); the 0.82 complete-link threshold is a starting point to tune from reviewed duplicates. No fixture pair collapsed at that threshold; grouping is exercised with derived synthetic events.
- Consent: recording consent is required for review; `training: false` turns remain reviewable and carry `training_consent: false` for downstream dataset filtering (§2.8). A conservative card-number screen is defence in depth, not a replacement for governance PII/redaction (P1-09/P3-10).
- P2-01 scores are consumed through duck-typed protocols; no import keeps this lane independent while P2-01 lands. Fixture tests use fakes derived from event metadata, never fixture failure labels. `FixtureTurnSource` reads labels only to locate events and checks call/turn agreement.
- `QueueItem.to_review_item()` matches `ReviewItemCreate` in the OpenAPI 1.0.0 contract (`no_prefill` → `blind`) but performs no HTTP push; P2-03 owns the adapter. Triages scores are hints, never human labels (§2.2), and fixtures are not the golden set (§2.5).
