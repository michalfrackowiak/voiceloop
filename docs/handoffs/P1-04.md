What changed (files/paths):
- `sdk/pipecat/__init__.py` — public re-exports for the optional integration.
- `sdk/pipecat/observer.py` — protocol shims (`FrameLike`, `UserAudioFrameLike`,
  `WordLike`, `SttFrameLike`, `ParserFrameLike`, `ConversationLike`, `TurnSink`)
  and `PipecatObserver`. Captures native-rate user PCM bytes (8 kHz unchanged),
  STT text + word confidences + decoder stats, parser input/output/validity/
  logprob, STT/parser model IDs and dialogue context; builds a schema-valid
  turn event and sends it through the narrow `TurnSink` protocol. Every public
  frame/lifecycle method swallows exceptions and counts them (`errors`,
  `dropped_events`, `events_built`, `events_sent`, `last_error`). No sync
  validation, logging or I/O runs in the call path (context.md §2.1).
- `sdk/pipecat/observer.py` also provides `InMemoryTurnSink` (deep-copy local
  ingest fake with optional validator and `drain()`), `SdkLogTurnSink` (lazy
  `from sdk import log_turn` inside `send`; in-memory fallback when unavailable
  or raising; `used_fallback`, `events`, `last_error`), `default_sink()`,
  `CapturedAudio`, `SttResult`, `ParserResult`, `WordConfidence`,
  `DecoderStats`, `DialogueContext`, `ConsentFlags`, `build_turn_event()` and
  `validate_turn_event()` (lazily calls `voiceloop_common.validate`).
- `sdk/pipecat/traces.py` — dependency-free OpenTelemetry-compatible shim:
  `SpanLike`, `DictSpan`, `TraceContext`, `current_span()` (lazy real OTel when
  installed, otherwise `None`), `bind_conversation_ids()` and constants
  `CALL_ID_ATTRIBUTE = "voiceloop.call_id"`,
  `CONVERSATION_ID_ATTRIBUTE = "voiceloop.conversation_id"`,
  `TURN_INDEX_ATTRIBUTE = "voiceloop.turn_index"`. The observer binds IDs to the
  dict context and the current span on every finished turn; schema
  `additionalProperties: false` keeps trace fields out of the event body.
- `sdk/pipecat/example.py` — stdlib-only scripted bot (`run_example()` and
  `main()`) producing three synthetic turns (16 kHz with word confidences,
  native 8 kHz, silence) into `InMemoryTurnSink(validator=validate_turn_event)`,
  with a `DictSpan` showing trace propagation. Run with
  `.\.venv\Scripts\python.exe -m sdk.pipecat.example`.
- `sdk/pipecat/README.md` — run/test/contract notes, fail-open policy, trace
  attribute table, public API, lazy-SDK fallback documentation.
- `tests/unit/pipecat/` — `__init__.py`, `fakes.py` (fake conversation driver
  implementing `ConversationLike`), `test_observer.py`, `test_traces.py`,
  `test_example.py` (13 tests covering schema validity via both
  `schemas.validate` and `validate_turn_event`, 8 kHz byte preservation, word
  confidences, parser/model/context data, trace attributes, SDK lazy import and
  fallback, fail-open on bad frames/broken sinks, deterministic IDs/timestamps,
  and the example CLI).
